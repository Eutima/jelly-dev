# Sample files

Pairs ending in `_v1` / `_v2` are meant to be compared:

| Pair | What it shows |
|---|---|
| `greeting_v1.go` / `greeting_v2.go` | renamed function, changed strings (word highlights), added function, syntax highlighting |
| `notes_v1.txt` / `notes_v2.txt` | plain text: changed words, added and deleted lines |
| `settings_v1.json` / `settings_v2.json` | small modifications spread over a file (several separate changes) |
| `report_v1.py` / `report_v2.py` | Python highlighting, inserted lines |
| `tabs_unicode_v1.txt` / `tabs_unicode_v2.txt` | tabs, accents, CJK characters (wide characters, tab stops) |
| `long_lines_v1.txt` / `long_lines_v2.txt` | very long lines (truncation with an ellipsis, narrow terminals) |
| `clipboard_sample.txt` | copy its content to the clipboard, then `jelly-diff --clip greeting_v1.go` |
| `empty.txt` | an empty file (everything is added or deleted) |

More inputs (binary files, CRLF, escape sequences, big files) are generated by `../setup.sh` into `../sandbox/`.
